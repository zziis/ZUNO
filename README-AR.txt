Zuno Final v1 — إعداد المشروع
=============================

هذا مشروع ويب كامل كبداية قابلة لاحقاً للتحويل إلى تطبيق Android رسمي.

الميزات المفعلة حالياً:
- أول شاشة: Zuno + تسجيل دخول / إنشاء حساب، بدون زائر.
- الدخول بـ ID أو البريد + كلمة المرور.
- زر عين لإظهار/إخفاء كلمة المرور.
- التسجيل: الاسم + البريد + كلمة المرور + التأكيد + ID دعوة اختياري.
- ID المستخدم ثابت ويتولد من 1000 صعوداً.
- حساب المطور مجهز ليصبح ID 1 وRole=developer.
- رصيدان منفصلان: النقاط والمجوهرات.
- إعدادات الحساب: ID ثابت، الاسم كل 7 أيام، البريد كل 7 أيام، كلمة المرور كل 24 ساعة، الهاتف قريباً.
- الإحالة: ID الدعوة الخاص بي + عدد الإحالات.
- الدعم الفني: 8 صباحاً إلى 8 مساءً بتوقيت بغداد + استقبال شكاوى + بوت أسئلة شائعة.
- الخاص: بحث بالـID، طلب صداقة مع نبذة، قبول/رفض، حالة اتصال، رسائل خاصة بين الأصدقاء.
- الرومات: إنشاء بـ500 نقطة، ID للروم، بحث بـID الروم أو المالك، رقم سري اختياري 1-4 أرقام، مالك/مشرف، كتم مؤقت ودائم، طرد، حظر، رفع/تنزيل مشرف.
- الأغاني والمايكات والهدايا داخل الروم: قريباً.
- العداد: ساعة رملية 24 ساعة + 50 مجوهرة عند الاكتمال، والوقت محفوظ في Supabase.
- شراء العدادات: 500/750/1000/2000/4000 — قريباً.
- المتجر: ID مميز 10-100، المظهر، الموبايل، الحاسوب، أرصدة آسياسيل/زين/كورك — قريباً.
- العجلة: عجلة المجوهرات وتحدي النقاط — قريباً.

خطوات Supabase:
1) أنشئ مشروع Supabase.
2) SQL Editor: شغّل database/zuno_supabase.sql مرة واحدة.
3) Edge Functions: أنشئ auth-login والصق supabase/functions/auth-login/index.ts ثم Deploy.
4) Edge Functions: أنشئ account-update والصق supabase/functions/account-update/index.ts ثم Deploy.
5) افتح js/config.js وضع Project URL وAnon Key.
6) أنشئ حسابك من واجهة Zuno باستخدام بريدك وكلمة مرورك.
7) افتح database/SET-DEVELOPER-ID-1.sql، استبدل YOUR-DEVELOPER-EMAIL@example.com ببريد حسابك، وشغله مرة واحدة.
8) بعد ذلك تسجيل دخول المطور يكون: ID = 1 + كلمة مرور نفس الحساب.

مهم:
- لا يمكن إنشاء كلمة مرور المطور تلقائياً داخل الملفات بدون معرفة بريدك وكلمة المرور وبدون وصول مباشر إلى مشروع Supabase؛ لذلك ملف SET-DEVELOPER-ID-1.sql يثبّت حسابك الحقيقي كـ ID 1 بعد إنشائه.
- SUPABASE_SERVICE_ROLE_KEY يبقى داخل Edge Functions فقط ولا يوضع أبداً في GitHub أو JavaScript.
- قبل Google Play سنحتاج إضافة سياسة الخصوصية، حذف الحساب، شروط الاستخدام، وربط APK/AAB بطريقة مناسبة.
